 Сайт

**[Открыть Math Rating](https://murmelow.github.io/math-rating/)**

## Текущая версия

Проект на стадии личного MVP.

### Возможности

* Персональный математический рейтинг
* Отдельный рейтинг по областям:

  * Алгебра
  * Геометрия
  * Математический анализ

* Ранги от `F` до `S+`
* Задачи с различной сложностью
* Изменение рейтинга в зависимости от сложности задачи и результата
* История решений
* Статистика точности
* Сохранение прогресса локально

## Рейтинг

Начальный рейтинг:

```text
1000
```

Ранги:

```text
F    < 800
D    800+
C    1000+
B    1200+
A    1400+
S    1600+
S+   1800+
```
